## 3. FiQA 2018 Sentiment Dataset

**Dataset:**  
TheFinAI/fiqa-sentiment-classification

**Platform:**  
Hugging Face

**Purpose in this project:**  
Primary offline financial dataset used for:
- Tableau dashboard
- Sentiment analysis
- Business-area and topic analysis
- AI POC evaluation

**Dataset size:**  
1,173 records

**Main fields used:**  
- sentence
- target
- aspect
- score
- type
- split

**Derived project fields:**  
- Business_Area
- Topic
- Sentiment_Category
